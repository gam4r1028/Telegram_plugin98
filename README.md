# Stranger Things Farewell Bot

В репозитории лежат две реализации одного и того же ностальгического бота:

- `exteragram_plugins/stranger_things_farewell.py` — плагин для exteraGram;
- `userbot/stranger_things_userbot.py` — автономный Telethon-юзербот.

Обе версии используют общую логику из `stranger_things/dialogue.py`, поэтому их поведение остаётся одинаковым.

## Возможности

- Команда запуска: `.strange` — бот предупреждает о возможных спойлерах, ждёт ответа «да/нет» и после подтверждения показывает меню.
- Команда остановки: `.stop` — бот мгновенно завершает сессию и забывает состояние.
- Для каждого сезона Stranger Things есть тёплое, ностальгическое описание с ключевыми моментами и атмосферой.
- Пункт `0` позволяет прокатиться по всем сезонам подряд.
- Пункт `6` — отдельная прощальная речь о сериале.
- Пункт `7` — сюжетная мини-игра с несколькими развилками и концовками, после финала бот возвращает пользователя в главное меню.

## Запуск exteraGram-плагина

1. Поместите файл `stranger_things_farewell.py` в каталог плагинов exteraGram.
2. Перезагрузите клиента или вручную загрузите модуль.
3. Используйте команды `.strange` и `.stop` в любом чате. Бот отвечает отдельными сообщениями, сохраняя общее настроение сериала.

## Запуск Telethon-юзербота

1. Установите зависимости: `pip install telethon`.
2. Установите переменные окружения `TG_API_ID`, `TG_API_HASH` и при необходимости `TG_SESSION` (название файла сессии).
3. Запустите `python userbot/stranger_things_userbot.py`.
4. После подключения в чате «Избранное» появится напоминание о командах. Дальше команды и ответы работают так же, как в плагине.

Обе реализации поддерживают несколько одновременных чатов: состояние запоминается отдельно для каждого `chat_id`.
